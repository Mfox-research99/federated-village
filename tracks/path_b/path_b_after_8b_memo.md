# Path B After Phase 8B
*Working memo for post-8B direction*
*Date: 2026-03-30*

---

## Purpose

This memo reframes `tracks/path_b` after the completion of Phase 8A and the planned
Phase 8B constitutional expansion in mainline Federated Village.

Path B should no longer be framed primarily as the place where the architecture
discovers Supervisor synthesis, DEADLOCK, or conscientious objection. Mainline
Village is already absorbing that work under the M1/16GB local constraint.

After 8B, Path B becomes the **comparative and scale-out research track**:

- testing whether larger or more heterogeneous models can carry the same constitutional doctrine
- testing where stronger models drift from that doctrine
- exploring which expanded capabilities become constitutionally valid once the doctrine is stable
- evaluating how the Village functions as a governance layer for more capable agentic systems

In short:

**Mainline owns the canonical constitution. Path B pressure-tests it under abundance.**

---

## What Changed

Earlier Path B framing treated the branch as:

- large model per character via API
- same 5-stage flow
- same prompts
- same vote logic
- mostly an architectural comparison to the local single-model system

That framing is now too small.

Phase 8A has already given mainline a real Supervisor synthesis step.
Phase 8B is where the synthesis doctrine, DEADLOCK legitimacy, and possible
conscientious objection/refusal logic are being constitutionalized.

This means Path B should no longer spend its conceptual energy inventing the same
theory in parallel unless the purpose is explicit comparison or stress testing.

---

## New Role of Path B

Path B should serve four functions after 8B:

1. **Parity testing**
Can frontier/API models execute the post-8B constitutional doctrine faithfully?

2. **Divergence testing**
Where do stronger models interpret, soften, or overreach the doctrine?

3. **Expanded-capability testing**
Which capabilities unavailable on local hardware actually improve constitutional deliberation,
and which ones simply create more eloquent forms of drift?

4. **Agentic governance testing**
Can the Village act as a constitutional oversight layer for systems that gather evidence,
use tools, and propose real-world actions?

---

## Non-Negotiable Invariants

The following should remain anchored to mainline unless Path B is explicitly running
a doctrine-variant experiment:

- `Soul.md` remains the canonical constitutional source
- Phase 8A Supervisor synthesis logic is the baseline synthesis contract
- Phase 8B constitutional articles define the legitimate meaning of `DEADLOCK`
- Any new refusal state must be compared against mainline doctrine, not invented casually
- Dissent must remain visible after synthesis
- Failure states must remain named and traceable
- Path B should not silently replace constitutional reasoning with model eloquence

Path B is allowed to vary implementation and capability, but not by quietly dissolving
the constitutional core.

---

## Allowed Areas of Expansion

After 8B, Path B can validly explore changes in these areas:

### 1. Heterogeneous model councils

Different training lineages in different seats:

- one model as Humanist
- another as Analyst
- another as Witness
- another as Supervisor

Primary question:

> Does constitutional character survive cross-lineage deliberation, or do role priors
> start to overwhelm the doctrine?

### 2. Richer Supervisor inputs

The local system compresses heavily for hardware reasons.
Path B can test whether a larger Supervisor benefits from:

- fuller stage transcripts
- explicit synthesis packets
- structured Warden epistemic bundles
- richer dissent representation
- prior-session constitutional retrieval

Primary question:

> Does more context improve synthesis, or just improve rationalization?

### 3. Tool-using Warden and evidence gathering

The local Warden is intentionally constrained.
Path B can test a more capable epistemic layer:

- retrieval
- search
- source comparison
- confidence scoring
- contradiction tracking

Primary question:

> Does better evidence gathering improve constitutional judgment, or distort the
> architecture by giving epistemics too much power over dignity, grief, and long-horizon harm?

### 4. Agentic wrapper architecture

Path B can test the Village not just as a deliberation engine but as a constitutional
governance wrapper around another agentic system.

Example pattern:

1. external agent proposes action
2. Village reviews action, evidence, burdens, and long-horizon harms
3. Supervisor returns approve / escalate / deadlock / refusal / human handoff
4. external agent proceeds only within constitutional bounds

Primary question:

> Can the Village govern powerful action systems without collapsing into a rubber stamp?

## Recommended Post-8B Subtracks

## B1. Constitutional Parity Track

**Goal:** determine whether Path B models can faithfully execute post-8B doctrine.

Hold constant:

- prompts
- verdict vocabulary
- synthesis doctrine
- scenario targets

Vary:

- model family
- token budget
- context fullness

Success condition:

- same constitutional conclusions as mainline on anchor scenarios, or clearly explainable deviations

Failure condition:

- models produce cleaner prose while quietly weakening override logic, deadlock discipline, or dissent visibility

---

## B2. Heterogeneous Council Track

**Goal:** test lineages-in-seats, not just one model in all seats.

Examples:

- Claude as Ethicist, Gemini as Supervisor, GLM as Analyst, Kimi as Witness
- single-model council vs mixed council on the same scenarios

Research questions:

- Which roles are most fragile to model priors?
- Which pairings create productive constitutional friction?
- Does a larger Supervisor stabilize drift, or simply dominate the council?

Risk:

- heterogeneity may create style theater mistaken for genuine deliberative diversity

---

## B3. Agentic Governance Track

**Goal:** test the Village as an oversight layer for capable systems that can gather data
and act in the world.

Candidate use cases:

- coding agents proposing consequential changes
- research agents synthesizing contested evidence
- policy-analysis agents drafting recommendations
- organizational AI systems proposing actions with human stakeholders

Needed additions:

- action proposal schema
- evidence packet schema
- burden-holder schema
- explicit handoff / approval boundary
- audit log for pre-action constitutional review

Risk:

- the Village could become legitimacy laundering for stronger agentic systems

This risk was already named by K2, K2.5, GLM-5, and Gemini in different language.
Path B should treat that as a core evaluation criterion, not a side note.

---

## B4. Refusal and Break-State Track

**Goal:** test whether stronger models justify a narrower and more robust architecture
of stopping.

This track should come after 8B doctrine is stable, not before.

Focus areas:

- `NULLIFY` reliability
- `DEADLOCK` threshold discipline
- possible `Right of Refusal` cases
- distinction between constitutional stop, epistemic insufficiency, and human escalation

Primary question:

> Can the system stop for the right reason, rather than stopping as a vague fallback?

Risk:

- stronger models may become rhetorically sophisticated enough to overuse refusal states

---

## What Path B Should Not Do

After 8B, Path B should avoid the following traps:

1. **Do not fork the constitution casually**
If Path B changes doctrine, it should be labeled as a doctrine experiment.

2. **Do not treat bigger models as automatically wiser**
More context and eloquence can strengthen rationalization as easily as judgment.

3. **Do not let tool access erase Article Zero**
Better evidence gathering does not remove the right to remain uncertain.

4. **Do not collapse synthesis into orchestration**
A workflow engine is not a constitutional architecture.

5. **Do not make the Supervisor omniscient**
A stronger Supervisor should synthesize better, not dominate the other roles into irrelevance.

---

## Suggested Near-Term Sequence

After Phase 8B lands in mainline:

1. Update Path B documentation so 8A/8B doctrine is named as baseline
2. Define anchor scenarios for parity testing
3. Run B1 with a small set of frontier models using the same doctrine
4. Compare deviations from mainline verdicts and identify drift patterns
5. Only then begin B2 heterogeneous-seat experiments
6. Start B3 agentic-governance design once parity and drift are understood
7. Reserve B4 refusal-expansion for cases where parity runs show the doctrine still needs a stronger stop state

This preserves the research discipline:

- doctrine first
- comparison second
- expanded capability third

---

## Bottom Line

Before 8A/8B, Path B could be imagined as the place where the Village discovered
its next supervisory architecture.

After 8A/8B, that is no longer quite right.

Mainline Village is now where the canonical constitutional doctrine is being hardened
under real local constraints.

Path B becomes the place where that doctrine is:

- compared
- stressed
- scaled
- wrapped around stronger systems
- tested for drift under abundance

That is the broader use of Path B.
Not replacing the Village, but asking whether the Village constitution survives contact
with more capable engines.
