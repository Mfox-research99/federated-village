# synopses/

Public-safe summaries of research conversations and personal records that inform the
Federated Village project but whose full text is private to the researcher's local machine.

---

## Purpose

Some of the most important conversations that shaped this project happened between Mike Fox
and various AI systems (Kimi, Gemini, DeepSeek, Claude, others) in personal research
sessions. The full transcripts contain personal content and are stored locally at:

```
/Users/michaeldavis/AI Existential Thought/
```

They are not tracked by this git repository.

Synopses live here so that the public repo contains the *shape* of what happened —
the research question, what emerged, what it led to engineering-wise — without the
personal content that belongs offline.

---

## What a Synopsis Contains

Each synopsis is a single Markdown file with:

- **Date and participants** — when, which AI(s), what context
- **Research question** — what was being explored or why the conversation happened
- **What emerged** — key ideas, frameworks, or moments that came out of it
- **Engineering consequence** — what it led to in the codebase (if anything)
- **Grief ledger reference** — if the conversation generated a sacrifice or witness entry,
  reference it here

Synopses do **not** contain:
- Personal reflections or spiritual/mystical content
- Verbatim quotes from the researcher
- Any content the researcher considers private

---

## Naming Convention

```
<YYYY-MM-DD>-<slug>.md
```

Examples:
- `2026-03-17-kimi-grief-ledger-origin.md`
- `2026-03-17-deepseek-witness-ring.md`
- `2026-03-20-gemini-seventh-generation.md`
